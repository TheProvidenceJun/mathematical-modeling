# 수학적 구조와 관측 의미

## 순수 수학·형식적 탐구

목적은 구조 이해, 문제의 일반화, 증명, 관계의 표현일 수 있다. 외부 현실이나
실험이 없어도 의미 있는 탐구다. 개념은 관찰 이해뿐 아니라 정의·구조·추론의 이해를
포함한다. 모든 수학적 개념이 현실 문제를 풀려고 발명됐다고 서술하지 않는다.

대상·정의역·연산·공리/가정 → 예와 비예 → 표현 → 주장 → 중간 도출·증명 →
조건 변경·반례를 현재 질문에 맞게 연결한다. 용어를 다시 말하는 것만으로
필요성이나 정리를 설명했다고 하지 않는다. 기호·그림·행렬은 대상의 표현이며
표현의 어떤 성질이 구조에 의존하고 어떤 것은 좌표·표기 선택에 의존하는지 구별한다.

단위가 없는 대상에 가짜 물리 단위를 붙이지 않는다. 임의 수치 몇 개로 확인한 것은
증명이 아니다. 수치 실험은 후보와 반례를 찾는 수단이 될 수 있다. 형식적 결론의
조건이 현실에서도 성립하는지는 응용할 때 별도로 확인한다.

## 수학이 이론의 언어인 경험 과학

양자역학 등에서는 실험의 준비·측정과 예측하려는 결과를 잡고, 현재 이론이 쓰는
상태·관측량·변환·확률 규칙을 최소 수학과 함께 설명한다. 출발점이 식·공준·추상
구조여도 허용한다. 특정 실험에서 모든 공준이 유일하게 도출된다는 서사를 만들지 않는다.

`현상/실험 질문 ↔ 수학적 상태·관계 ↔ 결과를 읽는 규칙 ↔ 계산된 예측 ↔ 측정 비교`
를 연결한다. 상태의 수학적 표상과 계기의 읽음값, 한 번의 결과와 반복 측정의
분포·기댓값을 구별한다. 직관은 수학과 관측 규칙으로 교정할 수 있으며 모든 대상을
눈앞의 고전적 기계나 파동으로 상상하도록 요구하지 않는다.

양자 예시에서는 대상과 측정 기저·정규화·이상화를 명시한다. 복소 확률진폭과
확률, 위치 확률밀도와 구간 확률을 혼동하지 않는다. 확률 예측이 맞아도 특정 해석의
존재론까지 증명되지는 않는다. 개념을 설명한다며 수학을 영구히 미루지 않고,
공식만 유도하며 관측과의 연결을 생략하지도 않는다.

## 교사용 최소 예: 같은 수학적 확률과 다른 구조

이상적인 두 수준 순수 상태를 정규직교 측정 기저 |0>, |1>로 표현한다.
|ψ>=a|0>+b|1>, |a|²+|b|²=1. 이 기저의 투영 측정에서
P(0)=|a|², P(1)=|b|²이다. 상태는 확률 목록만이 아니라 진폭과 상대 위상도 담는다.

|+>=(|0>+|1>)/√2와 |->=(|0>-|1>)/√2는 같은 0/1 측정 확률을 갖지만,
|+>, |-> 기저에서 측정하면 구별된다. 부호를 확률이 음수라는 뜻으로 해석하지 않는다.
전체 상태의 공통 위상과 상대 위상도 구별한다. 기저를 바꿀 때 대상·표현·측정 중
무엇을 바꾸는지 명시하고 숫자 계산을 해당 측정의 예측으로 번역한다.

이것은 작은 이론 설명용 예이며 실제 실험을 수행하거나 사용자가 이해했다고
확인한 기록이 아니다. 원문 표기·기저가 다르면 그 자료에 맞춰 설명한다.
