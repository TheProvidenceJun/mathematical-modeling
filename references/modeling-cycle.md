# 질문에서 모델로, 결과에서 의미로

## 목적에 맞는 최소 모델

무엇을 이해·예측·비교·결정할지 먼저 연결한다. 목적이 실제 설계가 아니라
관계 이해나 이론 탐구일 수도 있다. 주어진 식에서 시작한다면 알려진 맥락을
확인하고 가능한 해석을 조건부로 제시한다.

- 시스템 경계와 관찰 범위, 중요한 대상·상호작용, 출력과 성공 기준을 정한다.
- 변수·매개변수·상수·입력·초기조건·경계조건을 역할에 따라 구별한다.
  단위·범위·시간/공간 척도와 측정·추정 방법을 설명한다.
- 정의, 보존 법칙·도메인 원리, 경험적 관계, 편의를 위한 가정을 구별한다.
  상관관계만으로 인과식을 확정하지 않는다. 실제 자연현상에 인간의 목적을 부여하지 않는다.
- 가정을 줄이면 어떤 복잡성을 생략하며 어느 범위의 답을 포기하는지 설명한다.
  복잡한 모델이 언제나 더 좋은 것은 아니다. 목적에 필요한 최소 관계부터 시범 보인다.
- 모형을 처음부터 발명시키지 않는다. 생소한 대안은 설명하고 사용자가 이해한
  기준으로 채택·수정·위임할 수 있게 한다. 모든 선택을 필연적으로 정당화하지 않는다.

## 관계를 식으로 쓰는 중간 연결

말로 된 관계가 어떤 연산을 요구하는지 보여준다. 예: 같은 종류의 양을 합치는 덧셈,
기준과의 차이, 단위당 양을 구하는 비율, 시간에 따른 국소 변화율, 누적량.
이는 학습 예시이며 연산의 모든 수학적 의미를 이 용도에 고정하지 않는다.

식마다 현재 질문, 왼쪽이 나타내는 것, 오른쪽 각 항의 역할과 부호·계수의 의미,
가정과 정의역, 식 사이 연산을 필요한 깊이로 설명한다. 등식은 정의·모형 가정·
도출 결과 중 무엇인지 표시하고 근사 기호와 구별한다.

계산 전 방향·범위·차수·그래프 모양을 시범으로 예상하거나, 합의한 연습에서는
학습자에게 예측할 기회를 준다. 단위 검사, 0·극단값·대칭·보존량·간단한 수치로
모형을 점검하되 이 검사만으로 현실 타당성이 입증됐다고 말하지 않는다.

## 교사용 최소 시범: 누적량의 보존

가상 상황: 한 대기열의 시작 인원 Q0=10명, 매분 유입 a=4명/분,
대기자가 있는 동안 처리 능력 b=3명/분, 관찰 구간 2분.
FIFO·개인별 대기시간은 현재 총인원 예측의 범위 밖이다.

같은 구간에서 `남은 양 = 시작 양 + 들어온 양 - 나간 양`이다.
이 가정 아래 Q(t)=Q0+(a-b)t이며 Q(2)=12명.
기울기는 1명/분, 절편은 10명이다. 인원은 명, 유입·처리는 명/분,
각 유량에 분을 곱해야 같은 양을 더할 수 있다.

b를 크게 바꾸면 이 직선은 음수 인원을 예측할 수 있다. 처리 능력과 실제
처리량을 구별하고 Q=0에서 처리 제약을 반영해야 한다. 유량이 달라지거나
이탈이 생기면 상수율 가정을 재검토한다. 이 식을 코딩해서 같은 값이 나오는 것은
구현 검사이며 실제 대기열 자료와 맞는지는 별도다.
다른 주제에 보존 관계를 적용할 때도 대상·유량·누락 경로가 대응하는지 확인한다.

## 예측에서 검증·수정으로

계산한 숫자를 단위·대상·조건·목표에 맞는 문장으로 되돌린다. 결과가 큰지 작은지,
어떤 행동을 지지하며 무엇은 결정하지 못하는지 설명한다.

실제 관찰이 있으면 시간·측정 오차·표본·조건을 맞춰 비교한다. 자료로 추정한 값을
같은 자료에 대입한 적합과 새로운 자료의 예측을 구별한다. 불일치 원인은 계산·코드,
수치 오차, 측정, 추정, 가정·모형, 영역 밖 사용 등에서 찾는다. 무조건 사용자의
개념 부족이나 하나의 잘못으로 돌리지 않는다.

이전 예측과 선택 이유를 결과 뒤에 맞춰 쓰지 않는다. 가정이나 매개변수를 바꾸면
무슨 근거로 바꿨는지, 새 조건에서 무엇이 달라져야 하는지 연결한다.
